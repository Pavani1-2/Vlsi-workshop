# Standard-Cell Libraries

## Overview

This section covers the fundamentals of standard-cell libraries used during digital IC implementation.

## Topics Covered

- Standard-cell concepts
- Cell library organization
- Liberty (`.lib`) files
- Cell functionality
- Input and output pins
- Cell characteristics
- Timing information
- Power information
- Timing arcs

## Timing Information

Important parameters include:

- Propagation delay
- Rise and fall delay
- Setup time
- Hold time
- Clock-to-Q delay

## Learning Outcomes

- Understand the purpose of standard-cell libraries
- Identify basic information in a Liberty file
- Understand cell timing characteristics
- Relate library information to RTL synthesis
