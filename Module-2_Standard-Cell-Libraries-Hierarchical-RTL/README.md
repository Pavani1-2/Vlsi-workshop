# Module 2 — Standard-Cell Libraries & Hierarchical RTL

## Overview

This module focuses on understanding standard-cell libraries, timing information, hierarchical RTL architecture and sequential elements used in digital IC design.

## Topics Covered

- Standard-cell libraries
- Liberty (`.lib`) files
- Cell characteristics
- Timing parameters
- Timing arcs
- Propagation delay
- Setup and hold time
- Hierarchical RTL design
- Module instantiation
- Top-level and sub-module architecture
- Flip-flop fundamentals
- Sequential timing concepts
