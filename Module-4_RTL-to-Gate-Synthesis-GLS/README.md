# Module 4 — RTL-to-Gate Synthesis & Gate-Level Simulation

## Overview

This module focuses on converting RTL designs into synthesized gate-level representations and verifying their behavior through Gate-Level Simulation.

## Topics Covered

- RTL synthesis
- Logic synthesis
- Technology mapping
- Gate-level netlists
- Gate-Level Simulation (GLS)
- RTL vs Gate-Level Simulation
- Blocking assignments
- Non-blocking assignments
- Synthesis-oriented Verilog coding
- Post-synthesis verification
