# Linux Development Environment

## Overview

This section documents the Linux environment used for RTL and VLSI design activities.

## Topics Covered

- Linux terminal basics
- Directory navigation
- File and directory management
- Command-line workflow
- Working with project files
- Executing EDA tools from the terminal

## Purpose

A Linux-based environment provides the command-line workflow required for running Verilog simulation, waveform analysis and synthesis tools.

## Tools and Environment

- Linux / Ubuntu
- Terminal
- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys

## Learning Outcome

Developed familiarity with the Linux command-line environment and the basic workflow required for RTL design and VLSI tool execution.
