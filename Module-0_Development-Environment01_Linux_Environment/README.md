# Module 0 — Development Environment

## Overview

This module covers the development environment and tools required for RTL and VLSI design.

## Topics Covered

- Linux development environment
- VLSI laboratory environment
- EDA tool setup
- Verilog development environment
- Cloud and local lab environment
- Basic command-line workflow

## Tools

- Linux / Ubuntu
- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys
- SKY130

## Objective

To establish and verify a functional development environment for RTL design, simulation and synthesis.

## Learning Outcome

After completing this module, I gained familiarity with the Linux-based VLSI development environment and the tools required for subsequent RTL design and synthesis activities.
