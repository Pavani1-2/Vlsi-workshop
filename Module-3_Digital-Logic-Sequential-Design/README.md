# Module 3 — Digital Logic & Sequential Design

## Overview

This module focuses on the RTL modeling of combinational and sequential digital circuits, along with simulation, synthesis and optimization of sequential designs.

## Topics Covered

- Combinational logic
- Sequential logic
- RTL modeling
- Clock and reset
- Flip-flops
- Registers
- Lab 06
- Lab 07
- Sequential logic optimization
- Simulation and synthesis

## Combinational Logic

Combinational circuits produce outputs based on their present input conditions without storing previous state.

## Sequential Logic

Sequential circuits incorporate storage elements and their behavior depends on present inputs as well as previously stored state.
