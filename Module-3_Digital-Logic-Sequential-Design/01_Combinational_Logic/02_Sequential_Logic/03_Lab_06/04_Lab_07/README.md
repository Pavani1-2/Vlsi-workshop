# Lab 07 — Sequential Logic

## Overview

This laboratory exercise focuses on the implementation and verification of sequential RTL designs using clock-driven digital logic.

## Activities

- Sequential RTL design
- Clock and reset implementation
- Testbench development
- Functional simulation
- Waveform analysis
- Synthesis
- Result verification
