# RTL Simulation

## Overview

This section covers simulation of Verilog RTL designs to verify their functional behavior before synthesis.

## Topics Covered

- RTL simulation flow
- Icarus Verilog
- Compilation of Verilog source files
- Testbench execution
- Simulation output
- Error identification
- Functional verification
- Simulation debugging

## Learning Outcomes

- Compile Verilog RTL designs
- Run RTL simulations
- Identify functional errors
- Verify expected outputs
- Debug RTL designs using simulation results
